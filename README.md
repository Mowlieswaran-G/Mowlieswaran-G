<h3 align="center">AI-Powered Metal Surface Defect Detection</h3>

<p>
SurfaceAI is an AI-powered computer vision application designed to analyze metal surface images and identify potential surface defects.
</p>

<p>
The system uses a trained <b>ResNet-18</b> deep learning model to classify surfaces as normal or defective and combines AI prediction with OpenCV-based visual analysis.
</p>

<p>
<b>Key Features:</b>
</p>

<ul>
  <li>🤖 AI-based defect classification</li>
  <li>🔥 Heatmap visualization</li>
  <li>📦 Defect region localization</li>
  <li>📊 Defect probability</li>
  <li>🔎 Visual defect inspection</li>
  <li>🖼️ Interactive image upload</li>
</ul>
